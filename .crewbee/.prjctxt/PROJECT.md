# Project

## Project ID

crewbeelab-github-io

## Project Name

crewbeelab.github.io

## Objective

CrewBeeLab public website for presenting CrewBee v2.2.2 as a harness-adaptable Agent Team layer: maintainable Agent Team assets that can be projected into agent harnesses, with OpenCode as the first/current adapter. The site should explain task-specific teams, maintainable team assets, flexible single-agent vs multi-agent execution, context-isolated delegation, the built-in Coding Team, reusable Team templates, current OpenCode integration, and Project Context as a clearly marked next-stage capability.

## Constraints

- Follow the minimalism principle.
- Do not store secrets in .crewbee/.prjctxt/.
- Keep claims aligned with current product state: Project Context is positioned as "Next" rather than already complete.
- Maintain bilingual English/Chinese content parity and responsive visual consistency.
